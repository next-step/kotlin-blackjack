# kotlin-blackjack

## Blackjack 

- [ ] At the start of the game, each player receives two cards.
- [ ] Players can choose to draw additional cards as long as their total does not exceed 21.

Card

- [ ] Number cards are counted by their face value.
- [ ] Aces can count as either 1 or 11.

Card Number

- [x] Number or symbol (J, Q, K, A).
- [x] Face cards (King, Queen, Jack) are each worth 10.

Card Suit

- [x] Contains four card suits (Spades, Hearts, Diamonds, Clubs).

Deck

- [x] Deck must not contain duplicated cards.

Hands
- [x] Must have two cards to be initialized.
- [x] Should be able to add card to hands.
